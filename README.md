# SpaceSwitch — macOS Workspace Switcher

> Native macOS app to switch between workspace profiles instantly.

## Install karo (Customer ke liye)

1. **Download karo** `SpaceSwitch-1.0.0.dmg`
2. **Double click** karo DMG file par
3. **SpaceSwitch icon** ko **Applications** folder mein drag karo
4. **Applications** se open karo
5. Done! ✅

## System Requirements
- macOS 13.0 (Ventura) ya usse upar
- Apple Silicon (M1/M2/M3) ya Intel Mac
